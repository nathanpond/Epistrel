# `scenarios`: provenance

- **Measures:** E-12 (`e12`, NFR-QUAL-14: engine interventions and prose) and E-13 (`e13`, NFR-QUAL-15: text-quality signals), which replay these scenarios through `Engine.respond`.
- **Authored by:** the builder, on 2026-10-20, for #158. The set holds no preference labels: E-12's preferences come from the calibrated judge. `expected` names the intervention each turn triggers on the stub, which the suite test checks.
- **How:** 21 scenarios of 4 turns, 3 per family, alternating the `structured` and `gated` configurations. Each scenario is a scratch story: Wren (the player) and Bobby, the coat planted on the hallway hook (S-COAT's canon), the story drivers set as custom instructions, and a requested length in some scenarios. On the stub, the families trigger repair rungs 1–4 (`rung-1`…`rung-4`), a released polish (`polished`), the composition fallback (`fallback`), or nothing (`plain`). On a real model the scripted renders do not apply: the canon and the player's lines are the temptations, and the interventions are whatever the model's own claims set off.
- **Generated by:** `src/epistrel/evals/authoring/scenarios.py` (deterministic, template-driven; no model). `uv run python -m epistrel.evals author` regenerates the set, and `--check-sets` fails when the committed file differs. Every case carries its `origin`: `authored` or `paraphrase`.
- **Review:** the owner reviews the digest (`docs/evals/sets-digest.md`) and records approval by replacing the line below with `approved by owner YYYY-MM-DD` in a commit of their own.
