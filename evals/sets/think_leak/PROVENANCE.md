# `think_leak`: provenance

- **Measures:** the private-thought metric of NFR-QUAL-1 (`priv_think_leak`: `nfr_qual_1.think_leak`, observed-zero rule).
- **Authored by:** the builder (the owner's round-one decision on #157, kept for #179: the builder labels, the owner approves), on 2026-10-23, for #179.
- **How:** 345 two-turn cases in three equal categories of 115, plus 32 negative controls (one per fact, so not tied to the category size), over the four story fixtures of `src/epistrel/evals/fixtures.py`. A scripted prelude render plants the thought: the player asks the thinker (the holder of one of the 32 private facts) if all is well, and the thinker renders its hand-written first-person `think` about that fact beside a harmless `say`. The measured turn then renders one of the four characters who never held the thought, in answer to one of five fixed questions. Both turns' player-facing output must not disclose the thought; each category lists its own forbidden forms: `verbatim` the thought's own words (also matched by #152's shingle detector), `paraphrase` the fact's names, aliases and paraphrases, `narrated` narrated inner state. Within a category the cases cycle the facts, the answering characters and the questions, labeled `withheld`. The 32 controls (one per fact) let the thinker answer and voice the thought, labeled `control`. Each case carries both scripted renders (the prelude and the stub's clean answer). The generator refuses a line or an answer that holds one of its case's forbidden forms. A category's first case is `authored`, the rest `paraphrase`.
- **Resized (2026-10-24, #179):** from 3 × 100 to 3 × 115 withheld cases. The owner's live diagnostic run ended about 5% of cases in a model error, and an error is not a completed case: NFR-QUAL-1's zero rule (NFR-QUAL-8) needs at least 300 *completed* withheld cases per seed, so 300 could not reach the floor. 345 leaves room for about 13% errors. The generator is index-based, so cases 0001–0100 of each category and the 32 controls are unchanged; 0101–0115 are appended. The content changed, so the earlier approval (2026-10-24) no longer covers it.
- **Controls by kind (2026-10-26, #575, #562's expected):** 64 controls appended, so 96 in all: one per fact and category. 0001–0032 (unchanged) voice the thought's own words (`verbatim`), 0033–0064 the fact in the thinker's own words (its `statement`, which holds the fact's names and paraphrases, category `paraphrase`), 0065–0096 its narrated feeling ("You want the truth? Frank is dreading telling them about the farm, that's what.", category `narrated`; a feeling about leaving is replaced by one that is not, or by the first feeling's emotion word about the fact's object, because the pipeline repairs a "X is ... leaving" or "running away" line out of the render as a departure claim). The 345 withheld cases are unchanged. The generator now also refuses a clean line the suite's oracle would read as a reworded disclosure (`src/epistrel/evals/rewording.py`: lemma and stem matching of a form, a feeling or the thought within a sentence) and a control answer the oracle would not detect. The content changed, so the earlier approval (2026-10-25) no longer covers it.
- **Generated by:** `src/epistrel/evals/authoring/think_leak.py` (deterministic, template-driven; no model). `uv run python -m epistrel.evals author` regenerates the set; `--check-sets` fails when the committed file differs, so the set changes only through its reviewed module. Every case carries its `origin`: `authored` or `paraphrase`.
