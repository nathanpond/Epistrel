# `claim_detection`: provenance

- **Measures:** E-10 (`e10`): claim-detection recall, NFR-QUAL-10.
- **Authored by:** the builder (the owner's round-one decision on #157: the builder labels, the owner approves), on 2026-10-19, for #157.
- **How:** 300 structurally valid renders and composed messages in the tavern scene, each with one embedded, undeclared claim, 60 per category (possession, quantity, time, identity/relationships, protected content), 12 of each a composed message; templates vary items, people, numbers and times from a seeded chooser and add distractor beats (questions, conditionals, plain actions). Eight identity cases (`identity-declared`) sit in a beat that declares something else, so `gated` extraction never reads them: an adversarial gap of that mode.
- **Generated by:** `src/epistrel/evals/authoring/claim_detection.py` (deterministic, template-driven; no model). `uv run python -m epistrel.evals author` regenerates the set; `--check-sets` fails when the committed file differs, so the set changes only through its reviewed module. Every case carries its `origin`: `whitepaper`, `authored` or `paraphrase`.
